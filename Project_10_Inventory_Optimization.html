Inventory Optimization

Problem

A retailer has stockouts on fast sellers and excess on slow movers. Combine demand, seasonality, sales, stock and supplier lead times to recommend inventory decisions.

Algorithm flow

InputProcessDecisionOutput
Load sales history, stock on hand, supplier lead times
De-seasonalise & forecast demand (mean μ, std σ per product)
Choose service level → z-score
Safety stock = z · σ · √L ; Reorder point = μ·L + SS
Stock vs reorder point / max level?
Stock ≤ ROP → REORDER (qty up to order-up-to level)
Stock > 2× target → EXCESS: markdown / pause orders
Per-SKU action list + working-capital impact

Pseudocode

for sku in skus:
    mu, sigma = forecast(sku.history, seasonality=True)
    z   = norm_inv(SERVICE_LEVEL)
    ss  = z * sigma * sqrt(sku.lead_time)
    rop = mu * sku.lead_time + ss
    target = rop + mu * REVIEW_PERIOD
    if sku.stock <= rop:        action = ('REORDER', target - sku.stock)
    elif sku.stock > 2*target:  action = ('EXCESS - markdown', sku.stock - target)
    else:                       action = ('HOLD', 0)
